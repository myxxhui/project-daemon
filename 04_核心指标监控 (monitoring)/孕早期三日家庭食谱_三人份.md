## 一、用餐原则

| 原则 | 说明 |
|------|------|
| **午餐（三人）** | **至少 2 道菜**：① 硬菜主肉（让她吃满意）② 家常素菜/汤（补叶酸、解腻） |
| **晚餐（仅媳妇）** | 她一个人吃，**肉类约 150–250 g/餐**，鱼 1 小段或 1 条小的；另 2 人晚餐不列入本表 |
| 午餐肉量 | 主菜肉类 **合计约 500–700 g/餐**（三人分；她可适当多吃） |
| 五花肉技法 | 切薄片 → **干煎至半焦** → 再下配菜 **一锅炒**（对标五花肉炒土豆） |
| 孕早期安全 | 鱼、肉、蛋 **全熟**；忌生冷、酒精、高汞鱼；午餐素菜保证每天有绿叶菜 |
| 第二道菜 | 选 **快手的**：蒜蓉青菜、番茄炒蛋、紫菜蛋花汤等，不抢主肉风头 |
| **排骨要烂** | 红烧/炖汤类排骨以 **筷子能轻松戳透、入口脱骨** 为准，宁可多炖 10 分钟，不要嚼不动 |
| **辣味** | 她喜辣：**可适量加小米辣**（见 §1.1）；孕吐/烧心时减量或暂不加 |

### 1.1 排骨炖烂 + 小米辣调味（必读）

**排骨怎么炖才舒服**

1. **时间**：普通锅小火焖 **50–70 分钟**（一人份 250–300 g 也建议 ≥50 分钟）；电压力锅 **排骨/肉类模式 25–35 分钟**，自然泄压后再收汁。
2. **选料**：优先 **肋排、小排**，比大骨排更易烂。
3. **焯水后炖**：冷水下锅焯水去血沫，再炖，汤清肉不腥。
4. **辅助**：炖时加 **2 片姜 + 1 勺料酒**；想更快烂可加 **半勺醋**（醋味会挥发，不影响口感）。
5. **验收**：关火前用筷子戳排骨中心，**轻松戳穿** 再出锅；咬不动就继续炖 10 分钟。

**小米辣能不能加？——可以，适量**

| 情况 | 建议 |
|------|------|
| 她平时就吃辣、孕吐不重 | **可以加**：主菜起锅前切 **1–2 个小米辣**（去籽更温和）与蒜同炒，或炖排骨时放 **1 个整根** 同炖（辣味进汤、可捞出） |
| 孕吐明显 / 烧心 / 腹泻 | **先少放或不放**；用青椒代替提味，好转后再加一点 |
| 用量参考 | 一人晚餐：**1 个**；三人午餐硬菜：**2–3 个**，切碎即可，勿大量辣椒油空腹喝 |

> 孕早期没有「绝对禁食辣椒」，关键是 **全熟、适量、她吃着舒服**。若医生有医嘱忌口，以医嘱为准。

**哪些菜适合加小米辣**

- **推荐**：红烧排骨、排骨玉米汤、五花肉炒土豆/西兰花、牛肉炒青椒（与青椒同炒很搭）
- **慎加**：清蒸鱼、鲫鱼汤（腥味+辣易反胃，可改姜葱提味）
- **做法**：小米辣 **切段或圈**，和蒜片一起下锅爆香再下肉/菜，辣味更均匀。

## 二、6 月 1 日（周一）· 第 1 天 — 今晚开始

### 晚餐（今晚 · 仅媳妇一人份）

> 今晚来不及买带鱼；用家中现成排骨。**只给她一人做饭**，份量按下面来，不必按三人炖一大锅。

**菜 1：红烧排骨（主）**

| 食材 | 一人份用量 |
|------|------------|
| 排骨 | **250–300 g**（约 6–8 块肋排，优选小排/肋排） |
| 姜、葱、生抽、老抽、料酒、冰糖 | 适量 |
| 小米辣 | **1 个**（喜辣；可去籽；孕吐则省略） |
| 米饭 | 半碗–1 碗 |

**做法**

1. 排骨冷水焯水，洗净。
2. 锅少油，姜葱爆香；可在此步加 **小米辣圈** 轻炒出香（勿炒糊）。
3. 下排骨、料酒、生抽、老抽、冰糖，加热水 **刚没过**，大火烧开转小火。
4. 盖盖焖 **50–60 分钟**（或电压力锅 **排骨键 25–30 分钟** 后开盖收汁）。
5. 筷子能轻松戳透排骨再收汁 3 分钟；留少许浓汤拌饭。

**烂度标准**：入口 **轻松脱骨**，嚼两下就化，不要费牙。

**菜 2：蒜蓉青菜（可选，有则做）**

| 食材 | 一人份用量 |
|------|------------|
| 青菜 | 3–4 棵 |
| 蒜 | 2–3 瓣 |

**做法**：蒜蓉快炒 1 分钟，少盐，小盘即可。

**今晚时间建议**：17:00 开炖；18:30 收汁；19:00 她一人吃。

**要点**：宁可多炖 10 分钟也要 **烂**；辣度 **1 个小米辣** 起步，不舒服就减；**其余排骨留作明天午餐/他餐**。

## 三、6 月 2 日（周二）· 第 2 天

### 早餐：番茄牛肉粥 + 水煮蛋（三人份）

**食材**

| 食材 | 用量 |
|------|------|
| 大米 | 1 杯（约 150 g） |
| 牛里脊 / 牛肉末 | 300 g |
| 番茄 | 3 个（中等） |
| 鸡蛋 | 6 个 |
| 姜丝、盐 | 适量 |

**做法**

1. 大米洗净，加水煮粥（约 40 分钟，或电饭煲预约）。
2. 牛肉切薄片或切末，少许淀粉、盐抓匀；番茄切丁。
3. 粥快稠时加牛肉、番茄、姜丝，**煮至肉完全变色熟透**（约 8–10 分钟）。
4. 鸡蛋水煮 8–10 分钟；每人 2 枚，配粥食用。

---

### 午餐（三人 · 至少 2 道菜）

#### 菜 1（主肉）：半焦五花肉炒土豆 ⭐

| 食材 | 用量 |
|------|------|
| 五花肉 | **600 g** |
| 土豆 | 3 个（中等） |
| 蒜、生抽、老抽少许、盐、葱花 | 适量 |

**做法**

1. 五花肉切 **0.3 cm 薄片**；土豆切滚刀块，泡水沥干。
2. 大锅少油，五花肉分批发至 **两面半焦**；盛出后土豆煎至边缘微黄。
3. 倒回五花肉，加蒜、生抽、少许老抽，大火炒匀出锅；**肉明显多于土豆**。
4. **调味（可选）**：起锅前加 **小米辣 2 个**（切圈）与蒜同炒 10 秒，或炖土豆时放 1 个整辣同煮后捞出。

#### 菜 2：蒜蓉青菜

| 食材 | 用量 |
|------|------|
| 青菜 | 1 把（约 500 g） |
| 蒜 | 半头 |

**做法**：蒜蓉快炒 1–2 分钟，少盐，**单独一盘**上桌。

**午餐要点**：两道菜 **分开盛**；她先盛主肉菜，素菜各取一些。

### 晚餐（仅媳妇一人份）

> 明日采购带鱼、小份排骨见 §六。

**菜 1：香煎带鱼**

| 食材 | 一人份 |
|------|--------|
| 带鱼段 | **3–4 段**（约 200 g） |

**做法**：擦干抹盐胡椒，少油中火煎至两面金黄熟透。

**菜 2：排骨玉米汤（小碗）**

| 食材 | 一人份 |
|------|--------|
| 排骨 | 200 g（小排/肋排易烂） |
| 玉米 | 半根 |
| 小米辣 | **半个–1 个**（可选，炖进汤里提味） |
| 姜、料酒、盐 | 适量 |

**做法**：排骨焯水 → 砂锅加水、姜、料酒、小米辣（整根放，熟后可捞出）→ 小火炖 **50–60 分钟至排骨软烂** → 加玉米再炖 10 分钟 → 只盛 **1 大碗汤 + 几块脱骨排骨**，配半碗饭。

## 四、6 月 3 日（周三）· 第 3 天

### 早餐：鲜肉小馄饨（三人份）

**食材**

| 食材 | 用量 |
|------|------|
| 馄饨皮 | 2 包（约 60–75 只） |
| 猪肉馅 | 450 g |
| 紫菜、虾皮 | 各 1 小袋 |
| 葱花、盐 | 适量 |

**做法**

1. 肉馅加葱花、盐、少许清水，顺一个方向搅上劲。
2. 包馄饨（人均约 20–25 只）；沸水下锅，浮起后再煮 2 分钟。
3. 大碗里放紫菜、虾皮、盐，浇热汤，捞馄饨；分三碗。

---

### 午餐（三人 · 至少 2 道菜）

#### 菜 1（主肉）：牛肉炒青椒洋葱

| 食材 | 用量 |
|------|------|
| 肥牛卷 / 牛肉片 | **600 g** |
| 青椒 | 2 个 |
| 洋葱 | 1 个（大） |
| 蒜、生抽、蚝油、黑胡椒 | 适量 |

**做法**

1. 生牛肉卷沸水焯熟；青椒、洋葱切块，蒜爆香后炒软。
2. 下牛肉大火快炒，加生抽、蚝油、黑胡椒；**牛肉盛在上层**。
3. **调味（可选）**：爆香蒜时加 **小米辣 2 个** 切圈，与青椒同炒。

#### 菜 2：番茄炒蛋

| 食材 | 用量 |
|------|------|
| 鸡蛋 | 3 个 |
| 番茄 | 2 个 |
| 盐、糖少许 | 适量 |

**做法**：鸡蛋炒散盛出；番茄炒出汁后倒回鸡蛋，加盐调味，**单独一盘**。

---

### 晚餐（仅媳妇一人份）

**一道主餐：鲫鱼豆腐汤**（鱼 + 汤合一锅，算她晚饭全部）

| 食材 | 一人份 |
|------|--------|
| 鲫鱼 | **1 条**（约 350–400 g，偏小即可） |
| 嫩豆腐 | **半块** |
| 姜、葱、盐、白胡椒粉 | 适量 |
| 米饭 | 半碗 |

**做法**

1. 鲫鱼洗净吸干，两面煎微黄；加开水、姜片，大火煮 10 分钟至汤白。
2. 下豆腐再煮 5 分钟，调味撒葱花；**鱼肉须煮透**，她一人喝一碗汤、吃一条鱼。

**备选**：改 **鲈鱼 1 条清蒸**（水开后蒸 10 分钟，淋蒸鱼豉油）+ 半碗饭。

## 五、6 月 4 日（周四）· 续做（计划收尾）

### 早餐：肉末蒸蛋 + 花卷（三人份）

**食材**

| 食材 | 用量 |
|------|------|
| 鸡蛋 | 6 个 |
| 猪肉末 | 240 g |
| 温水、生抽、香油、葱花 | 适量 |
| 花卷 / 馒头 | 9 个 |

**做法**

1. 每碗 2 个鸡蛋打散，加 1.5 倍温水、少许盐，过滤进碗（共 3 碗）。
2. 肉末 80 g/碗，加生抽拌开铺在蛋液上；盖保鲜膜扎孔。
3. 水开后 **中火蒸 12–15 分钟**，完全凝固后淋香油、葱花。
4. 每人 1 碗蒸蛋 + 3 个花卷。

## 七、执行备忘（准爸爸 / 阿姨）

- **分工**：**午餐** 三人、**至少 2 道菜**（一硬菜一素菜/汤）；**晚餐** 只给媳妇做，**份量约午餐 1/3**。
- **今晚（6/1）**：她一人 **排骨 250–300 g + 青菜**；排骨务必 **炖 50 分钟以上至烂**；可加 **1 个小米辣**。
- **「吃满意」**：固定在 **午餐主肉菜**；晚餐清淡、够她一个人吃饱即可。
- **孕吐期**：午餐硬菜放她胃口好的日子；晚餐鱼腥重可改清蒸、少油；**辣以她不反胃为准**。
- **排骨类**：一律按 §1.1 **炖烂** 再出锅，勿赶时间。
- **安全**：肉鱼蛋全熟；叶酸见 [孕早期文档](../01_文档与里程碑%20(docs)/v1_孕期养胎主线/01_孕早期_0至12周.md)。
- **打卡**：午餐记三人完成度；晚餐单独记她是否吃完。
